# Theory of Mind Experiments

Open `index.html` to explore Aces and Eights (Zhang et al., 2021) and Cheryl’s Birthday (Minculescu et al., 2025). Both experiments use the model of Top et al. (2024) to show how each public announcement updates the model and what responses it predicts at each order of reasoning.

The [ToMfa page](tomfa.html), linked at the bottom right of the card experiment, shows the update sequence and predicted responses for two specific deals. See [tomfa.pdf](tomfa.pdf) for the model definition.
